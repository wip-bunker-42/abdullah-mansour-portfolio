## Designed for access {#approach}

This website aims to meet WCAG 2.2 AA. It uses semantic headings, visible keyboard focus, readable contrast, responsive layouts and reduced-motion support. English and Arabic have their own language and reading direction.

## Navigation and forms {#navigation}

A skip link moves directly to the main content. Core pages, evidence links, the CV and the contact form work without JavaScript. Forms use visible labels and linked error messages.
